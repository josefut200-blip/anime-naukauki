SOBRE A KAGESTREAM

Seu próximo mundo favorito está a um play.

A KageStream é uma interface estática para descobrir animes, organizar favoritos e continuar assistindo sem depender de uma conta ou de um servidor pago. O catálogo é atualizado pela Jikan API e os vídeos são cadastrados localmente pelo administrador do projeto.

01Descoberta inteligente

Temporada, popularidade, notas e busca em um só lugar.

02Seu espaço pessoal

Favoritos e histórico ficam salvos no seu navegador.

03Feito para a web aberta

Hospede grátis em GitHub Pages, Netlify ou Vercel.
