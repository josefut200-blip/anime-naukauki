SOBRE A KAGESTREAM

Um catálogo para organizar o que assistir — não para hospedar o que não é nosso.

A KageStream nasceu de um problema simples: encontrar o próximo anime certo dá mais trabalho do que deveria. O projeto resolve a parte da descoberta e da organização, deixando claro de onde vêm os dados e os vídeos.

Como o catálogo é montado

As informações de cada título — sinopse, nota, gêneros, ano e capa — vêm da Jikan API, uma API pública que espelha dados do MyAnimeList. O catálogo cresce e se atualiza automaticamente, sem reivindicar autoria sobre esse conteúdo informativo.

De onde vêm os vídeos

Diferente do catálogo, os vídeos não são buscados automaticamente: eles são cadastrados manualmente pelo administrador do site, usando links verificados.

  • Vídeos próprios — conteúdo gravado, editado ou produzido pela equipe.
  • Domínio público — obras cujos direitos autorais já expiraram.
  • Conteúdo autorizado — embeds oficiais de plataformas e canais que permitem a incorporação do próprio player.

A KageStream não baixa, não re-hospeda e não distribui arquivos de vídeo de terceiros sem autorização. Quando um anime está disponível apenas em serviços licenciados, priorizamos o player oficial.

O que fica salvo no seu navegador

Favoritos, histórico de episódios e a lista “Minha lista” ficam salvos somente neste navegador e dispositivo, usando o localStorage. Se você trocar de aparelho ou navegador, ou limpar os dados do site, essa lista será reiniciada. A KageStream não sincroniza esses dados entre dispositivos.

Por que um site estático

A KageStream roda inteira no front-end e pode ser hospedada gratuitamente em GitHub Pages. Não há banco de dados pago nem backend para manter no ar; em troca, o cadastro de vídeos é manual.

Perguntas diretas

Vocês hospedam os vídeos?
Não. Vídeos próprios ficam em serviços externos; o restante é embed autorizado de outra plataforma.

Posso pedir um anime?
Sim — use a página de contato. Se houver uma fonte autorizada disponível para embed, o título entra na fila de cadastro.

Encontrei um link quebrado?
Avise pela página de contato com o nome do anime e o número do episódio.
