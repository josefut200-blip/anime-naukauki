SOBRE A KAGESTREAM

Seu próximo mundo favorito está a um play.

A KageStream é uma experiência gratuita para descobrir animes, salvar favoritos e continuar assistindo diretamente no navegador.

01

Descoberta inteligente

Temporada, popularidade, notas, gêneros e busca organizados em uma interface rápida.

02

Seu espaço pessoal

Favoritos e histórico ficam salvos localmente no navegador, sem exigir uma conta.

03

Web aberta

O projeto pode ser hospedado gratuitamente em GitHub Pages, Netlify ou Vercel.

Como funciona

O catálogo usa a Jikan API para buscar informações públicas sobre animes. Os vídeos são cadastrados pelo administrador usando links próprios, de domínio público ou devidamente autorizados.

Favoritos, histórico e cadastros locais usam o armazenamento do próprio navegador. Isso mantém o projeto simples, gratuito e fácil de publicar.
