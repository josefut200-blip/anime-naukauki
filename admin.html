PAINEL DE ADMINISTRAÇÃO

Cadastrar e corrigir vídeos

Use este painel para corrigir o anime, o episódio ou o código iframe. Os dados ficam salvos somente neste navegador.

Como publicar o catálogo

  1. Cadastre ou edite o anime e os episódios neste painel.
  2. Clique em Exportar catálogo ou exporte o catalogo.js conforme o botão disponível.
  3. Substitua o arquivo exportado no repositório GitHub.
  4. Faça commit e aguarde alguns minutos pela atualização do GitHub Pages.

Importante: o cadastro local não altera o site público até o arquivo exportado ser commitado.
